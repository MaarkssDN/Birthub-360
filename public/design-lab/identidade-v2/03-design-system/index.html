Design System V2.0

Sistema Operacional de Inteligência Comercial, impulsionado por IA e Revenue Intelligence. Um único sistema de tokens e componentes serve ao produto inteiro; o que muda entre módulos é um acento, e o que muda entre telas é a leitura.

Rascunho não homologado. Cores, tipografia (Sora, Inter, IBM Plex Mono), modos Dark/Light e a arquitetura vêm da missão (FONTE-DE-VERDADE.md, decisões C01 a C09). Todo o resto é derivação ou proposta do agente 03a e aparece marcado PROVISÓRIO, DERIVADO ou CONFIRMADO. Total atual: 252 tokens (10 confirmado · 8 oficial-existente · 27 herdado-core · 32 derivado · 168 provisorio · 7 herdado-motion).

Hub Central + Workspaces Modulares + Assistentes Globais (C07). O Hub é a entrada e o seletor; cada workspace é uma área de trabalho de um módulo; os assistentes ficam acoplados a qualquer workspace.

O mapeamento módulo → acento é PROPOSTA provisória. Só 8 nomes foram confirmados pelo Agente 00 (P01 a P06, P08, M10). Uso

<section data-theme="light" data-module="p03">   /* data-module SEMPRE abaixo de data-theme */
  .nav[aria-current="page"] { background: var(--module-accent-tint); }
  .nav[aria-current="page"] svg { color: var(--module-accent); }   /* texto/ícone: variante AA do tema */
  .chip { background: var(--module-accent-fill); color: var(--module-accent-on); } /* superfície neon sólida */

O acento nunca é o único identificador: nome, código (P01) e ícone acompanham sempre (WCAG 1.4.1). Com 11 módulos e 4 matizes, 3 ou 4 módulos compartilham cada cor por desenho; a distinção vem do código e do nome.

O nível é escolhido pelo atributo data-motion, o mesmo interruptor do 04-motion-system: commercial (Experiência Comercial e Leitura) usa a escala do brandbook, com corpo de 16px; operational (padrão, workspaces) usa a escala operacional, com corpo de 14px. Em [data-motion="commercial"] os tokens --text-*, --lh-* e --fw-* são remapeados para --text-c-*; componentes e títulos não mudam de código. Prosa corrida (≥ 2 linhas) usa 16px e entrelinha de 1,6 a 1,7 (BB-TIPO-07); os 14px operacionais valem só para tabelas, campos, menus e rótulos.

Escala comercial conferida em 02-brandbook/index.html e regras.json (BB-TIPO-06, PROVISÓRIA): display 72/76 (Sora 800), H1 48/52 (700), H2 36/40 (700), H3 24/30 (600), H4 18/24 (600), corpo 16/27 (Inter 400), apoio 13/19 (500), dados 14/20 (Plex Mono 500). O brandbook não define H5/H6: herdam a escala operacional.
