## Causa raiz

### Bugs (reliability)

O SonarQube (typescript:S9383) classifica como **BUG** qualquer chamada de função que retorna
Promise sem `await`/`.catch`/`.then`/`void`. O refactor moveu código mas preservou chamadas
fire-and-forget não marcadas:

1. `Overview.tsx` (useEffect de mount): `fetchChecklist()`, `fetchCalls(signal)`,
   `fetchAgents(signal)`, `fetchReady(signal)`, `fetchMetrics(signal)` — 5 promises soltas.
   Todas já tratam erros internamente (try/catch → status `'error'`), então o correto é
   marcar como explicitamente ignoradas com `void` (opção sancionada pela própria regra).
2. `studioServerActions.ts` `publishWorkflowToServer`: `get().fetchWorkflowVersions()` sem
   await dentro de função async → agora `await` (o refresh do painel de versões passa a fazer
   parte do ciclo de vida da action; já é guardado por epoch internamente).
3. `studioServerActions.ts` `openVersionHistory`: mesma chamada em função síncrona → `void`.

Issues BUG legadas em `useStudioStore.ts` (linhas 946/981 da versão pré-refactor, consultadas
via API pública do SonarCloud `api/issues/search?componentKeys=MarksNN_Birthub-360:...`) foram
movidas para `workflowPersistence.ts`/`studioServerActions.ts` — as ocorrências nos arquivos
novos eram exatamente as acima. Nenhum outro padrão de bug (catch vazio, JSON.parse sem try,
array[0] sem guarda, comparação inválida) foi encontrado nos arquivos novos — verificado
estaticamente e via API do SonarCloud.
