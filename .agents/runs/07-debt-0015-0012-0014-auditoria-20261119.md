## DEBT-0015 — CORRIGIDO

`src/features/intelligence/tools/scriptAndPromptTool.ts`: removido o `fallback` inline de
`generateTextOutput` que fabricava roteiro comercial (`# [ARTIFACT] ... Abertura Quebra-Gelo ...`)
e o persistia em `prisma.prompt.create({ approved: true })`. Sem fallback, falha do gateway
propaga exceção → a tool retorna `{ error }` honesto e **nada é persistido**. `approved: true`
permanece apenas para conteúdo realmente gerado pelo modelo (semântica pré-existente preservada;
`Prompt.approved` já tem `@default(false)` no schema — nenhuma migração necessária, schema é do 01
e não foi tocado).

Nota: os outros 3 branches da tool (`sales_pitch`, `objection_rebuttal`, `email_sequence`) usam
`features.ts → callModel → getAiModel`, que não possui fallback fabricado — já eram fail-loud.

Teste de regressão: `src/features/intelligence/tools/__tests__/scriptAndPromptTool.test.ts`
(2 testes): falha do gateway → `error` retornado e `prisma.prompt.create` **não chamado**;
sucesso → `prompt.create` chamado 1× com `approved: true` e conteúdo idêntico ao do gateway
(sem template fabricado).
